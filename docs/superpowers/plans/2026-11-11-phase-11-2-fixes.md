# Faz 11.2 — PR #21 Son Düzeltmeler Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bağımsız doğrulamada tespit edilen 5 bulguyu (dinamik ve fail-closed sitemap, dürüst a11y/klavye test raporlaması, Medusa üretim `secure` çerez varsayılanı, bağımsız arama indeks modülü/migration'ı ve mağaza aksiyon/sayfalama/checkout yarış durumu düzeltmeleri) TDD disipliniyle çözmek ve temiz veritabanında uçtan uca doğrulamak.

**Architecture:**

- **Sitemap (`apps/web/src/app/sitemap.ts` & `apps/web/src/lib/cache-tags.ts`):** `export const dynamic = "force-dynamic"` ile `next build` sırasında statik donmayı engeller; `catch {}` bloklarını kaldırarak DB veya Medusa API hatasında sessiz boş 200 yerine hata fırlatır (HTTP 500). Payload koleksiyonlarında (`Pages`, `Posts`, `PostCategories`) `CACHE_TAGS.sitemap()` etiketini de geçersiz kılar.
- **A11y ve Klavye Testleri (`apps/web/src/tests/a11y-axe.test.ts`, `keyboard-nav.test.ts`, `scripts/verify-quality.ts`):** Sunucu kapalıyken sessiz `return` (sahte yeşil) yerine `ctx.skip()` ile açıkça `skipped` raporlar; `REQUIRE_LIVE_SERVER=true` verildiğinde sunucu yoksa kırmızı (FAIL) verir; `verify:quality` içinde canlı sunucuya karşı zorunlu koşturulur.
- **Medusa Çerez Güvenliği (`apps/medusa/src/env.ts`, `apps/medusa/medusa-config.ts`):** `resolveCookieSecure` yardımcı fonksiyonu ile `NODE_ENV === "production"` ortamında varsayılan `secure: true` döner; üretimde `COOKIE_SECURE=false` verilirse açılışta fail-closed hata fırlatır. Development ortamında `localhost` HTTP akışı korunur.
- **Arama İndeksleri (`apps/medusa/src/modules/search-indexes/`):** `email-settings` altındaki kırılgan migration kaldırılır; `search-indexes` modülü ve `loaders/search-indexes.ts` ile `idx_product_title_trgm`, `idx_product_subtitle_trgm`, `idx_product_status` indeksleri idempotent olarak oluşturulur; `pg_trgm` yetki senaryosu `docs/RUNBOOK.md` ve `docs/SEARCH.md` içinde belgelenir.
- **Küçük Düzeltmeler:** Server action hata mesajları sabit Türkçe metin döner; `/urunler` ve `/kategori/[slug]` sınır dışı `page` değerlerinde yönlendirme yapar; sonsuz kaydırma üst sınırı katalog `totalPages` değerine bağlanır; COD hizmet bedeli rozeti yalnızca COD etkinse gösterilir; `/api/checkout` eşzamanlı tamamlama yarış durumunda deterministik `[200, 409]` döner.

**Tech Stack:** Next.js 15, Payload CMS 3, Medusa v2, PostgreSQL 16, Vitest, Playwright, TypeScript.
